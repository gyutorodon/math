基底・次元・座標

基底は空間の「ものさし（座標軸）」の選び方、次元はそのものさしの本数です。同じベクトルでも、基底を変えると座標の数値が変わります。

1. 何の話か（直感）

平面上の点を (3, 1) のように2つの数で表せるのは、「x 方向に1目盛り」「y 方向に1目盛り」という2本のものさし e1 = (1, 0), e2 = (0, 1) を決めているからです。

しかし、ものさしは斜めでも、長さがばらばらでも構いません。条件は次の2つだけです。

  • むだがない（一次独立）：どのものさしも、ほかのものさしで代用できない
  • 足りている（生成する）：空間のどのベクトルも、ものさしの組み合わせで表せる

この2条件を満たすものさしの組を基底、その本数を次元といいます。ℝ² の基底はどう選んでも必ず2本です。そして、ベクトルを基底の組み合わせで表したときの係数が座標です。同じ矢印でも、ものさしを変えれば座標は変わります。下の図で確かめましょう。

基底を変えると座標が変わる

基底を選ぶと、その基底の「斜めの方眼」が表示されます。●x をドラッグしてベクトルを変えられます。●b1, ●b2 をドラッグすると、自分で基底を決められます。

2. 定義

定義 1（生成する部分空間）

a1, …, ak の一次結合全体

⟨a1, …, ak⟩ = { c1a1 + ⋯ + ckak | ci ∈ ℝ }

は部分空間です。これを a1, …, ak が生成する（張る）部分空間といいます。V = ⟨a1, …, ak⟩ のとき、a1, …, ak は V を生成するといいます。

定義 2（基底）

線形空間 V のベクトルの組 (b1, …, bn) が次の2条件を満たすとき、V の基底といいます。

(B1)b1, …, bn は一次独立である (B2)b1, …, bn は V を生成する
定理 1（次元）

V の基底に含まれるベクトルの本数は、基底の選び方によらず一定です。この本数を V の次元といい、dim V と書きます。ただし dim { 0 } = 0 と約束します。

定義 3（座標）

(b1, …, bn) を V の基底とすると、各 v ∈ V は

v = x1b1 + x2b2 + ⋯ + xnbn

とただ1通りに表せます。この係数を並べた t(x1, …, xn) ∈ ℝⁿ を、基底に関する v の座標（座標ベクトル）といいます。

1通りである理由：2通り Σxibi = Σyibi に書けたとすると Σ(xi − yi)bi = 0。一次独立なので xi = yi。

定理 2（次元がわかっているとき）

dim V = n とします。V の n 本のベクトルについて、

一次独立である　⇔　V を生成する　⇔　基底である

つまり本数が次元と一致していれば、(B1) と (B2) の片方を確かめるだけで基底だとわかります。特に ℝⁿ の n 本は「列に並べた行列の行列式 ≠ 0」なら基底です。

3. 具体例

例 1：ℝⁿ の標準基底

e1 = (1, 0, …, 0), …, en = (0, …, 0, 1) は ℝⁿ の基底（標準基底）で、dim ℝⁿ = n。標準基底に関する座標は、ベクトルの成分そのものです。

例 2：ℝ² の別の基底と座標

b1 = (1, 1), b2 = (−1, 1) は det 1−111 = 2 ≠ 0 なので基底です（定理2）。v = (3, 1) の座標を求めるには x1b1 + x2b2 = v を解きます。

x1 − x2= 3x1 + x2= 1　⇒　x1 = 2,　x2 = −1

よってこの基底に関する座標は (2, −1) です。標準基底での座標 (3, 1) とは違う数になります。

確認：2(1, 1) − (−1, 1) = (3, 1)。

例 3：多項式の空間

ℝ[x]2 の基底として (1, x, x²) がとれるので dim ℝ[x]2 = 3（一般に dim ℝ[x]n = n + 1）。f = 3 − x + 2x² の座標は (3, −1, 2) です。

別の基底 (1, x − 1, (x − 1)²) をとると、x² = 1 + 2(x − 1) + (x − 1)² なので、x² の座標は (0, 0, 1) から (1, 2, 1) に変わります。

例 4：行列の空間

M2(ℝ) の基底として

E11 = 1000,　E12 = 0100,　E21 = 0010,　E22 = 0001

がとれるので dim M2(ℝ) = 4。abcd = aE11 + bE12 + cE21 + dE22 です。

例 5：部分空間の基底と次元

W = { x ∈ ℝ³ | x1 + 2x2 − x3 = 0 }。x3 = x1 + 2x2 なので、x1 = s, x2 = t とおくと

x = sts + 2t = s101 + t012

この2本は W を生成し、第1・第2成分を見れば一次独立です。よって基底は (1, 0, 1), (0, 1, 2) で、dim W = 2（平面）です。

4. よくある間違い

(1, 0), (0, 1), (1, 1) は ℝ² を生成するので基底である。

生成はしますが、(1, 1) = (1, 0) + (0, 1) なので一次独立ではありません。基底は独立かつ生成の両方が必要です。ℝ² の基底は必ず2本です。

ベクトル (3, 1) の座標は、どんな基底でも (3, 1) である。

(3, 1) は標準基底に関する座標です。基底 ((1, 1), (−1, 1)) に関する座標は (2, −1) です。座標は基底を決めて初めて決まります。

基底 (b1, b2) と (b2, b1) は同じなので、座標も同じ。

座標を考えるときの基底は順番つきです。順番を入れ替えると座標の成分も入れ替わります。

ℝ³ の中の、式1本で定まる部分空間 W は「式が1本だから1次元」。

式は自由度を減らすものです。独立な式が1本なら dim W = 3 − 1 = 2。基底を実際に求めて本数を数えるのが確実です。

零空間 { 0 } の基底は 0 なので、次元は 1。

0 だけの組は一次従属なので基底になれません。{ 0 } の基底は空集合で、dim { 0 } = 0 です。

5. 練習問題

問題 1

b1 = (1, 2), b2 = (3, 4) が ℝ² の基底であることを確かめ、v = (5, 6) のこの基底に関する座標を求めてください。

解答を見る

det 1324 = 4 − 6 = −2 ≠ 0 なので、2本は一次独立で、ℝ² の基底です（定理2）。

x1 + 3x2= 52x1 + 4x2= 6　⇒　x1 = −1,　x2 = 2

座標は (−1, 2)。

確認：−(1, 2) + 2(3, 4) = (5, 6)。

問題 2

W = { x ∈ ℝ⁴ | x1 + x2 + x3 + x4 = 0,　x1 − x2 = 0 } の基底と次元を求めてください。

解答を見る

2式目から x2 = x1。1式目に入れて x4 = −2x1 − x3。x1 = s, x3 = t とおくと

x = sst−2s − t = s110−2 + t001−1

この2本は W を生成し、第1・第3成分を見れば一次独立です。よって基底は (1, 1, 0, −2), (0, 0, 1, −1)、dim W = 2。

問題 3

ℝ[x]2 の基底 (1, 1 + x, 1 + x + x²) に関する、f = 3 − x + 2x² の座標を求めてください。

解答を見る

a · 1 + b(1 + x) + c(1 + x + x²) = (a + b + c) + (b + c)x + cx² を f と比べて

c = 2,　b + c = −1,　a + b + c = 3　⇒　a = 4,　b = −3,　c = 2

座標は (4, −3, 2)。

確認：4 − 3(1 + x) + 2(1 + x + x²) = 3 − x + 2x²。
