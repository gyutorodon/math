1. 計算のコツ（まとめ）

偏微分の基本ルール
  1. 微分しない文字は定数：∂∂x(x3y2) = 3x2y2, ∂∂x(y2) = 0, ∂∂x(eyx) = ey。
  2. 積・商の微分はそのまま使える：(uv)x = uxv + uvx, uvx = uxv − uvxv2。
  3. 合成関数：{g(u)}x = g′(u)ux（「外の微分 × 中の偏微分」）。例：{sin(x2y)}x = cos(x2y) · 2xy。
  4. 連鎖律：zu = zxxu + zyyu。経由する変数の数だけ項を足す。
  5. 検算：fxy = fyx になるか（C2 級なら必ず一致）。

2. 型別の例題

型 A：偏導関数（商・合成）

f = arctanyx。u = yx とおくと ux = −yx2, uy = 1x。

fx = 11 + (y/x)2 · −yx2 = −yx2 + y2, fy = 11 + (y/x)2 · 1x = xx2 + y2

11 + (y/x)2 = x2x2 + y2 と整理するのがポイント。

型 B：2次偏導関数とラプラス方程式

f = log(x2 + y2) について fxx + fyy = 0 を示す。fx = 2xx2 + y2 を商の微分で

fxx = 2(x2 + y2) − 2x · 2x(x2 + y2)2 = 2(y2 − x2)(x2 + y2)2

x と y を入れ替えると fyy = 2(x2 − y2)(x2 + y2)2。足して 0。（fxx + fyy = 0 をみたす関数を調和関数といいます。）

型 C：連鎖律（具体的な関数）

z = x2 + xy + y2, x = 2t + 1, y = t2。

dzdt = (2x + y) · 2 + (x + 2y) · 2t = 4t3 + 6t2 + 10t + 4

最後に x = 2t + 1, y = t2 を代入して t だけの式に。直接 z = t4 + 2t3 + 5t2 + 4t + 1 を微分しても同じです。

型 D：連鎖律（抽象的な関数）

z = f(u, v), u = x2 − y2, v = 2xy のとき zx, zy を fu, fv で表す。

zx = fu · 2x + fv · 2y, zy = fu · (−2y) + fv · 2x
型 E：定義による計算・全微分可能性

f(x, y) = x2y2x2 + y2 ((x, y) ≠ (0, 0)), f(0, 0) = 0。軸上で f = 0 なので fx(0, 0) = fy(0, 0) = 0。極座標で

f(h, k) − 0 − 0 · h − 0 · k√h2 + k2 = r4cos2θsin2θr3 ≤ r → 0

よって原点で全微分可能（接平面は z = 0）。

答え合わせ

入力のしかた：かけ算は * か省略（2xy）、累乗は ^、関数は sin cos tan exp log sqrt arctan、e^(…) も可。log は自然対数です。

4. よくある間違い

∂∂xexy = exy。

合成関数なので中身の偏微分を掛けます：∂∂xexy = exy · y = yexy。

∂∂yxy に商の微分を使い 1 · y − x · 1y2。

y で微分するとき x は定数なので (x)y = 0。0 · y − x · 1y2 = −xy2。あるいは x · y−1 と見て −xy−2 とすれば速い。

fxy を求めるのに、fx と fy を掛ける。

fxy = (fx)y：fx をさらに y で偏微分したものです。

5. 練習問題

問題 1 型A 偏導関数

次の fx, fy を求めてください。

(1) x3y2 − 4xy + y5　(2) (2x − y)4　(3) xe−xy　(4) sin(x2y)　(5) xyx + y　(6) xy (x > 0)　(7) log√x2 + y2

解答を見る

(1) fx = 3x2y2 − 4y, fy = 2x3y − 4x + 5y4

(2) fx = 8(2x − y)3, fy = −4(2x − y)3

(3) fx = e−xy − xye−xy = (1 − xy)e−xy, fy = −x2e−xy

(4) fx = 2xycos(x2y), fy = x2cos(x2y)

(5) fx = y(x + y) − xy(x + y)2 = y2(x + y)2, fy = x2(x + y)2

(6) fx = yxy − 1（y は定数なので累乗の微分）, fy = xylogx（x は定数なので指数関数の微分）

(7) 12log(x2 + y2) と直して fx = xx2 + y2, fy = yx2 + y2

問題 2 型B 2次偏導関数

fxx, fxy, fyy を求めてください。

(1) x4 + x2y3 − y2　(2) excosy　(3) sin(x + 2y)　(4) xy

解答を見る

(1) fx = 4x3 + 2xy3, fy = 3x2y2 − 2y。fxx = 12x2 + 2y3, fxy = 6xy2, fyy = 6x2y − 2

(2) fxx = excosy, fxy = −exsiny, fyy = −excosy（fxx + fyy = 0：調和関数）

(3) fxx = −sin(x + 2y), fxy = −2sin(x + 2y), fyy = −4sin(x + 2y)

(4) fx = 1y, fy = −xy2。fxx = 0, fxy = −1y2, fyy = 2xy3

問題 3 型B 調和関数

f(x, y) = xx2 + y2 が fxx + fyy = 0 をみたすことを示してください。

解答を見る

fx = (x2 + y2) − 2x2(x2 + y2)2 = y2 − x2(x2 + y2)2, fy = −2xy(x2 + y2)2。

fxx = −2x(x2 + y2)2 − (y2 − x2) · 2(x2 + y2) · 2x(x2 + y2)4 = 2x3 − 6xy2(x2 + y2)3
fyy = −2x(x2 + y2)2 + 2xy · 2(x2 + y2) · 2y(x2 + y2)4 = −2x3 + 6xy2(x2 + y2)3

足して 0。（分子・分母を (x2 + y2) で1回約分するのがコツ。）

問題 4 型C・D 連鎖律

(1) z = sin(xy), x = t2, y = et のとき dzdt。

(2) z = x2 − y2, x = rcosθ, y = rsinθ のとき zr, zθ。

(3) z = f(x, y), x = u + v, y = uv のとき zu, zv を fx, fy で表してください。

解答を見る

(1) dzdt = ycos(xy) · 2t + xcos(xy) · et = (2tet + t2et)cos(t2et) = t(t + 2)etcos(t2et)

(2) zr = 2xcosθ − 2ysinθ = 2r(cos2θ − sin2θ) = 2rcos2θ、zθ = 2x(−rsinθ) − 2y(rcosθ) = −4r2sinθcosθ = −2r2sin2θ。（z = r2cos2θ と一致。）

(3) xu = 1, yu = v, xv = 1, yv = u より zu = fx + vfy, zv = fx + ufy。

問題 5 型E 定義

f(x, y) = xy2x2 + y2 ((x, y) ≠ (0, 0)), f(0, 0) = 0 について、fx(0, 0), fy(0, 0) を求め、原点で全微分可能か調べてください。

解答を見る

f(h, 0) = 0, f(0, k) = 0 より fx(0, 0) = fy(0, 0) = 0。

f(h, k)√h2 + k2 = hk2(h2 + k2)3/2 \xrightarrowh = k h32√2|h|3 =  ± 12√2\not → 0

よって全微分可能でない。

問題 6 偏微分方程式

(1) u(x, t) = e−tsinx が熱方程式 ut = uxx をみたすことを示してください。

(2) z = x2y + y3 のとき、xzx + yzy = 3z を確かめてください（z は3次の同次式）。

解答を見る

(1) ut = −e−tsinx, ux = e−tcosx, uxx = −e−tsinx。等しい。

(2) zx = 2xy, zy = x2 + 3y2。xzx + yzy = 2x2y + x2y + 3y3 = 3(x2y + y3) = 3z。（一般に n 次の同次式なら xzx + yzy = nz：オイラーの定理。）
