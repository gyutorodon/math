1次独立と1次従属

ベクトルの組に「むだ」があるかどうかを判定します。むだのない組を1次独立、むだのある組を1次従属といいます。判定は同次連立1次方程式を解くことに帰着します。

1. 何の話か（直感）2. 定義3. 具体例4. よくある間違い5. 練習問題▶ 動かしてみよう
この回のポイント（まずここだけ押さえましょう）
  1. 1次独立＝「むだがない」：どのベクトルも、ほかのベクトルの組み合わせでは作れない状態です。
  2. 判定はベクトルを列に並べた行列 A で行います。rank A = 本数なら独立です（正方行列なら |A| ≠ 0 でも判定できます）。
  3. 図で見ると、ℝ² の2本が同一直線上、ℝ³ の3本が同一平面上にあると従属です。

1. 何の話か（直感）

ベクトルをいくつか持っているとき、「その中のどれかが、ほかのベクトルの組み合わせで作れてしまう」なら、そのベクトルはむだです。持っていなくても、同じものが作れるからです。

  • ℝ² の2本のベクトルが同一直線上にあると、片方はもう片方の定数倍です。2本あっても「1方向」にしか進めません。
  • ℝ³ の3本のベクトルが同一平面上にあると、どれか1本は残り2本の組み合わせで作れます。3本あっても「平面」の中しか動けません。

むだがない状態を1次独立、むだがある状態を1次従属といいます。図で言えば、ℝ² では2本が作る平行四辺形の面積、ℝ³ では3本が作る平行六面体の体積が 0 になるかどうかです。下の「動かしてみよう」で、ベクトルを動かして確かめてください。

●a1、●a2 をドラッグしてください（格子点に吸着します）。色の付いた平行四辺形の面積が det(a1 a2) の絶対値です。

成分を変えてください（▲▼ で 1 ずつ動かせます）。図はドラッグすると回転します。a1, a2 が張る平面を緑で表示しています。

2. 定義

定義（1次結合・1次関係）

ベクトル a1, …, ak と実数 c1, …, ck に対し、c1a1 + ⋯ + ckak を1次結合（線形結合）といいます。また

c1a1 + c2a2 + ⋯ + ckak = 0　　(★)

の形の式を1次関係といいます。c1 = ⋯ = ck = 0 なら (★) はいつも成り立ちます（自明な1次関係）。

定義（1次独立・1次従属）

「係数を全部 0 にする以外に、足して 0 にする方法がない」のが独立、「ほかにもある」のが従属です。

  • (★) を満たす (c1, …, ck) が c1 = ⋯ = ck = 0 しかないとき、a1, …, ak は1次独立であるといいます。
  • 少なくとも1つは 0 でない (c1, …, ck) で (★) が成り立つとき、1次従属であるといいます。
定理 1（従属の言いかえ）

a1, …, ak が1次従属 ⇔ どれか1つのベクトルが、残りのベクトルの1次結合で書ける。

理由：cj ≠ 0 なら (★) を cj で割って移項すると aj = −Σi≠j (ci/cj) ai となります。

定理 2（連立方程式による判定）

ベクトルを列に並べて簡約化し、ピボットが本数ぶんあれば独立です。

a1, …, ak ∈ ℝⁿ を列に並べた n × k 行列を A = (a1 ⋯ ak) とすると、(★) は同次連立1次方程式 Ac = 0（c = t(c1, …, ck)）です。よって

1次独立　⇔　Ac = 0 の解が c = 0 だけ　⇔　rank A = k
  • k = n（正方行列）のときは：1次独立 ⇔ det A ≠ 0（教科書の記号では |A| ≠ 0）
  • k > n のときは：rank A ≤ n < k なので必ず1次従属

3. 具体例

例 1：ℝ² の2本（従属）

a1 = (1, 2), a2 = (2, 4) は a2 = 2a1 なので、2a1 − a2 = 0 という自明でない1次関係があります。よって1次従属です。実際 det 1224 = 4 − 4 = 0。

例 2：ℝ³ の3本（独立）

a1 = (1, 1, 0), a2 = (0, 1, 1), a3 = (1, 0, 1)。c1a1 + c2a2 + c3a3 = 0 を成分で書くと

c1 + c3= 0c1 + c2= 0c2 + c3= 0

1式目と2式目から c3 = −c1, c2 = −c1。3式目に入れると −2c1 = 0 より c1 = 0、したがって c1 = c2 = c3 = 0。1次独立です（det = 2 ≠ 0 でも確認できます）。

例 3：ℝ³ の3本（従属）— 行基本変形で判定

a1 = (1, 2, 3), a2 = (2, −1, 1), a3 = (3, 1, 4) を列に並べて簡約化します。

A = 1232−11314 → 1230−5−50−5−5 → 101011000

rank A = 2 < 3 なので1次従属です。最後の行列から c1 = −t, c2 = −t, c3 = t。t = 1 として −a1 − a2 + a3 = 0、つまり a3 = a1 + a2（3本は同一平面上）です。

例 4：多項式（独立）

ℝ[x]2 の 1, 1 + x, 1 + x + x² について、

c1 · 1 + c2(1 + x) + c3(1 + x + x²) = (c1 + c2 + c3) + (c2 + c3)x + c3x² = 0

が多項式として 0 なので、各係数が 0：c3 = 0, c2 = 0, c1 = 0。1次独立です。

例 5：関数（独立）

sin x, cos x について、すべての x で c1 sin x + c2 cos x = 0 とします。x = 0 を代入すると c2 = 0、x = π/2 を代入すると c1 = 0。よって1次独立です。

例 6：本数が多すぎる（必ず従属）

ℝ³ の4本 (1, 0, 0), (0, 1, 0), (0, 0, 1), (1, 2, 3) は、定理2より（4 > 3）計算しなくても1次従属です。実際 (1, 2, 3) = 1·(1, 0, 0) + 2·(0, 1, 0) + 3·(0, 0, 1)。

4. よくある間違い

ℝ³ の3本で、どの2本も平行でないから1次独立である。

3本が同一平面上にあれば従属です。たとえば (1, 0, 0), (0, 1, 0), (1, 1, 0) はどの2本も平行ではありませんが、(1, 1, 0) = (1, 0, 0) + (0, 1, 0) なので従属です。

c1 = c2 = c3 = 0 を代入すると (★) が成り立つので、1次独立である。

自明な解 c = 0 はどんなベクトルでも成り立ちます。示すべきなのは「(★) が成り立つならば c1 = ⋯ = 0」という向きです。(★) を仮定して係数を求めましょう。

0 を含む組でも、ほかのベクトルが独立なら全体も独立である。

0 を含む組は必ず従属です。1 · 0 + 0 · a2 + ⋯ = 0 が自明でない1次関係だからです。

ベクトルを行に並べて簡約化し、その結果から係数 ci を読み取る。

rank（独立かどうか）は行に並べても列に並べても同じですが、1次関係の係数を読み取るには列に並べた Ac = 0 を解く必要があります。

5. 練習問題

解き方の手順：1次独立かどうかの判定
  1. ベクトルを列に並べて行列 A を作ります。
  2. A を簡約化して rank A を求めます（正方行列なら |A| を計算しても構いません）。
  3. rank = 本数 なら独立、rank < 本数 なら従属です。
  4. 従属のときは、簡約化した行列から Ac = 0 の解を読み取り、1次関係を書きます（自由変数を 1 とおくと簡単です）。

文字のベクトル（a, b, c など）の証明問題は、「x(…) + y(…) + z(…) = 0 とおく → a, b, c ごとにまとめる → 独立性から各係数 = 0 → 連立方程式を解く」の順に進めます。

問題 1 教科書 練習問題4 [A] 11 の類題

ℝ³ のベクトル a = 102, b = 213, c = 01−1 について、a, b, c は1次独立か、また ℝ³ を生成するかを調べてください。さらに、v = t(v1, v2, v3) が ⟨a, b, c⟩ に属するための条件を求めてください。

解答を見る
12001123−1 → 1200110−1−1 → 10−2011000

rank = 2 < 3 なので1次従属で、ℝ³ を生成しません。最後の行列から 2a − b + c = 0、つまり c = b − 2a なので、⟨a, b, c⟩ = ⟨a, b⟩（原点を通る平面）です。

v ∈ ⟨a, b⟩ となる条件は、sa + tb = v が解をもつことです。拡大係数行列を変形すると

12v101v223v3 → 12v101v20−1v3 − 2v1 → 12v101v200v3 − 2v1 + v2

解をもつのは最後の行が 0 = 0 のとき、つまり 2v1 − v2 − v3 = 0 です。

確認：a は 2 − 0 − 2 = 0、b は 4 − 1 − 3 = 0、c は 0 − 1 + 1 = 0 で、どれも条件を満たします。

問題 2

(1, 1, a), (1, a, 1), (a, 1, 1) が1次従属になるような実数 a をすべて求めてください。

解答を見る

3本を列に並べた行列式が 0 になる a を求めます。

11a1a1a11 = (a − 1) − (1 − a) + a(1 − a²) = −(a − 1)²(a + 2)

よって a = 1, −2。

確認：a = 1 なら3本とも (1, 1, 1)。a = −2 なら3本の和が (0, 0, 0)。

問題 3 教科書 練習問題4 [B] 5, 6 の類題

a1, a2, a3 が1次独立であるとします。

(1) a1 − a2, a2 − a3, a3 も1次独立であることを示してください。
(2) a1 − a2, a2 − a3, a3 − a1 は1次従属であることを示してください。

解答を見る

(1) x(a1 − a2) + y(a2 − a3) + za3 = 0 と仮定して整理すると

xa1 + (y − x)a2 + (z − y)a3 = 0

a1, a2, a3 は1次独立なので x = 0, y − x = 0, z − y = 0。順に解いて x = y = z = 0。よって1次独立です。

(2) 3本をすべて足すと (a1 − a2) + (a2 − a3) + (a3 − a1) = 0。係数 (1, 1, 1) は 0 でないので、これは自明でない1次関係です。よって1次従属です。
