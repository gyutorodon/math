極値問題

山頂・谷底では接平面が水平、つまり fx = fy = 0。その点が山頂か谷底か鞍点かは、2次の項（fxx, fxy, fyy）でつくる判別式 H = fxxfyy − f2xy の符号で判定します。

1. 何の話か（直感）2. 定義・定理3. 具体例▶ 停留点を探す4. よくある間違い5. 練習問題

1. 何の話か（直感）

曲面 z = f(x, y) の「山頂（極大）」や「谷底（極小）」を探します。山頂ではどちら向きにも平ら、つまり接平面が水平です。だから極値の候補は

fx(a, b) = 0, fy(a, b) = 0

をみたす点（停留点）です。ただし停留点がすべて極値とは限りません。馬の鞍のように「ある向きには上り、別の向きには下り」という鞍点もあります（z = x2 − y2 の原点）。

見分けるには、第5回のテイラー展開を使います。停留点では1次の項が消えるので

f(a + h, b + k) − f(a, b) ≈ 12Ah2 + 2Bhk + Ck2, A = fxx,  B = fxy,  C = fyy

右辺の2次式が「どんな (h, k) ≠ (0, 0) でも正」なら谷底（極小）、「いつも負」なら山頂（極大）、「正にも負にもなる」なら鞍点です。平方完成すると

Ah2 + 2Bhk + Ck2 = Ah + BAk2 + AC − B2Ak2

となり、符号は A と AC − B2 で決まることがわかります。

2. 定義・定理

定義（極大・極小）

点 (a, b) に十分近いすべての点 (x, y) ≠ (a, b) で f(x, y) < f(a, b) となるとき、f は (a, b) で極大、f(a, b) を極大値といいます。不等号が逆なら極小・極小値。両者をあわせて極値といいます。

定理 1（極値の必要条件）

f が (a, b) で極値をとり、偏微分可能ならば fx(a, b) = fy(a, b) = 0。

x ↦ f(x, b) は x = a で極値をとるので1変数の定理から fx(a, b) = 0。fy も同様。逆は成り立ちません（鞍点）。

定理 2（極値の判定）

f は C2 級で、fx(a, b) = fy(a, b) = 0 とします。A = fxx(a, b), B = fxy(a, b), C = fyy(a, b),

H = AC − B2 = fxxfxyfxyfyy
H の符号A の符号結論
H > 0A > 0極小
H > 0A < 0極大
H < 0—極値ではない（鞍点）
H = 0—この方法では判定できない

fxxfxyfxyfyy をヘッセ行列、H をヘッシアン（ヘッセ行列式）といいます。線形代数の言葉では「固有値がともに正なら極小、ともに負なら極大、異符号なら鞍点」です。

極値を求める手順
  1. fx, fy, fxx, fxy, fyy を計算する。
  2. 連立方程式 fx = 0, fy = 0 を解いて停留点をすべて求める（割り算で解を落とさないよう、因数分解して場合分け）。
  3. 各停留点で H, A を計算し、表にあてはめる。
  4. H = 0 の点は、直線や曲線に沿って f の符号の変化を調べるなど、個別に考える。
（参考）有界閉集合での最大・最小

有界閉集合 D 上の連続関数は最大値・最小値をもちます。それは「D の内部の停留点」か「D の境界上」でとられるので、両方の候補の値を比べれば求まります（問題6）。

3. 具体例

例 1：基本

f = x2 + xy + y2 − 4x − 2y。fx = 2x + y − 4 = 0, fy = x + 2y − 2 = 0 を解いて (x, y) = (2, 0)。

A = 2, B = 1, C = 2, H = 4 − 1 = 3 > 0, A > 0 なので極小。極小値 f(2, 0) = 4 − 8 = −4。

例 2：停留点が複数

f = x3 + y3 − 3xy。fx = 3x2 − 3y = 0, fy = 3y2 − 3x = 0 より y = x2, x = y2。代入して x = x4、x(x − 1)(x2 + x + 1) = 0 より x = 0, 1。停留点は (0, 0), (1, 1)。

fxx = 6x, fxy = −3, fyy = 6y。

  • (0, 0)：H = 0 · 0 − 9 = −9 < 0 → 鞍点（極値でない）
  • (1, 1)：H = 36 − 9 = 27 > 0, A = 6 > 0 → 極小、極小値 f(1, 1) = −1
例 3：H = 0 のとき

f = x4 + y4, g = x4 − y4, k = x2 + y3 はどれも原点が停留点で H = 0 です。

  • f：(x, y) ≠ (0, 0) なら f > 0 = f(0, 0) なので極小。
  • g：x 軸上では g = x4 > 0、y 軸上では g = −y4 < 0。原点のどんな近くにも正の点と負の点があるので極値でない。
  • k：y 軸上で k = y3 は y の符号で正負が変わるので極値でない。

このように H = 0 のときは定理2では何もわからず、関数の形を直接調べる必要があります。

4. よくある間違い

H > 0 だから極大。

H > 0 だけでは極大か極小か決まりません。A = fxx の符号を見ます（A > 0 なら極小、A < 0 なら極大）。

H = 0 だから極値ではない。

H = 0 は「判定できない」です。例3の x4 + y4 のように極小のこともあります。

fx = y(2x + y − 3) = 0 の両辺を y で割って 2x + y − 3 = 0 とする。

y = 0 の場合が抜けてしまいます。積  = 0 は「y = 0 または 2x + y − 3 = 0」と場合分けし、fy = 0 の場合分けとすべての組み合わせを調べます（問題3）。

fx = fy = 0 をみたす点を求めたので、それが極値である。

停留点は「極値の候補」にすぎません。必ず H で判定し、鞍点を除きます。

5. 練習問題

問題 1 基本

f(x, y) = x2 − 2xy + 2y2 − 2x + 4 の極値を求めてください。

解答を見る

fx = 2x − 2y − 2 = 0, fy = −2x + 4y = 0 より (x, y) = (2, 1)。A = 2, B = −2, C = 4, H = 8 − 4 = 4 > 0, A > 0。極小値 f(2, 1) = 2。

問題 2 停留点が2つ

f(x, y) = x3 − 3x + y2 の極値を求めてください。

解答を見る

fx = 3x2 − 3 = 0, fy = 2y = 0 より停留点 ( ± 1, 0)。A = 6x, B = 0, C = 2。

(1, 0)：H = 12 > 0, A = 6 > 0 → 極小値 f(1, 0) = −2。(−1, 0)：H = −12 < 0 → 鞍点（極値でない）。

問題 3 場合分け

f(x, y) = xy(x + y − 3) の極値を求めてください。

解答を見る

f = x2y + xy2 − 3xy。fx = y(2x + y − 3), fy = x(x + 2y − 3)。

fx = 0 ⇔ y = 0 または 2x + y = 3、fy = 0 ⇔ x = 0 または x + 2y = 3。組み合わせて停留点は (0, 0), (3, 0), (0, 3), (1, 1)。

A = 2y, B = 2x + 2y − 3, C = 2x。

  • (0, 0)：H = 0 − 9 < 0、(3, 0)：H = 0 − 9 < 0、(0, 3)：H = 0 − 9 < 0 → いずれも鞍点
  • (1, 1)：A = 2, B = 1, C = 2, H = 3 > 0 → 極小値 f(1, 1) = −1

上のデモで x y (x+y-3)、範囲 ±3 で確かめられます。

問題 4 4次関数

f(x, y) = x4 + y4 − 4xy の極値を求めてください。

解答を見る

fx = 4x3 − 4y = 0, fy = 4y3 − 4x = 0 より y = x3, x = y3 = x9。x(x8 − 1) = 0 より x = 0,  ± 1。停留点 (0, 0), (1, 1), (−1, −1)。

A = 12x2, B = −4, C = 12y2。(0, 0)：H = −16 < 0 → 鞍点。( ± 1,  ± 1)：H = 144 − 16 = 128 > 0, A = 12 > 0 → 極小値 −2（2点とも）。

問題 5 H = 0

f(x, y) = x2 + y3 および g(x, y) = x2 + y4 について、原点が極値かどうか調べてください。

解答を見る

どちらも原点は停留点で A = 2, B = 0, C = 0、H = 0（判定不能）。

f：y 軸上で f(0, y) = y3 は y > 0 で正、y < 0 で負。極値でない。

g：(x, y) ≠ (0, 0) で g = x2 + y4 > 0 = g(0, 0)。極小（極小値 0）。

問題 6 最大・最小

f(x, y) = x2 + y2 − 2x の、円板 D :  x2 + y2 ≤ 4 における最大値と最小値を求めてください。

解答を見る

内部：fx = 2x − 2 = 0, fy = 2y = 0 より (1, 0)、f(1, 0) = −1。

境界 x2 + y2 = 4：f = 4 − 2x（−2 ≤ x ≤ 2）なので、x = 2 で 0、x = −2 で 8。

比べて 最大値 8（点 (−2, 0)）、最小値 −1（点 (1, 0)）。
