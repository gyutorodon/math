基底変換と座標変換

同じベクトルを2種類の基底で測ると、座標の数値が変わります。その「換算表」が変換行列 P です。P の作り方と、座標の変換公式 x = Px′ を学びます。

1. 何の話か（直感）2. 定義3. 具体例4. よくある間違い5. 練習問題▶ 動かしてみよう

1. 何の話か（直感）

長さを「メートル」で測るか「フィート」で測るかで数値が変わるように、ベクトルも基底（ものさし）を変えると座標の数値が変わります。第3回で見たとおり、v = (3, 1) は標準基底では (3, 1)、基底 ((1, 1), (−1, 1)) では (2, −1) でした。

基底を変えるたびに連立方程式を解くのは大変です。そこで、

  1. 「新しい基底の各ベクトルを、古い基底で表すと何か」を1つの行列 P（基底の変換行列）にまとめておき、
  2. 座標の換算は行列のかけ算 x = Px′ で済ませる

というのが今回の話です。ポイントは、基底は P で「古い→新しい」に変わるのに、座標は逆向きの式になることです。下の計算機で確かめてみましょう。

2. 定義

線形空間 V の2組の基底を B = (b1, …, bn)（古い基底）、B′ = (b′1, …, b′n)（新しい基底）とします。

定義（基底の変換行列）

新しい基底の各ベクトルを古い基底の一次結合で表します。

b′j = p1jb1 + p2jb2 + ⋯ + pnjbn　　(j = 1, …, n)

この係数を第 j 列に並べた n 次正方行列 P = (pij) を、B から B′ への基底の変換行列といいます。まとめて書くと

(b′1 ⋯ b′n) = (b1 ⋯ bn) P

つまり P の第 j 列 = b′j の B に関する座標 です。P は必ず正則です。

定理（座標変換の公式）

v ∈ V の B に関する座標を x、B′ に関する座標を x′ とすると

x = Px′，　　x′ = P−1x

証明：v = (b′1 ⋯ b′n)x′ = (b1 ⋯ bn)Px′。一方 v = (b1 ⋯ bn)x。座標はただ1通りなので x = Px′。

ℝⁿ での求め方

V = ℝⁿ なら、基底のベクトルを列に並べた行列を同じ記号 B, B′ で表すと、B′ = BP なので

P = B−1B′

特に B が標準基底なら P = B′（新しい基底をそのまま列に並べたもの）です。

3. 具体例

2つの基底で座標を換算する計算機

基底 B, B′ のベクトルを列として入力してください。v の B 座標 x から、変換行列 P と B′ 座標 x′ を計算します。分数（例 1/2）も入力できます。2次元のときは図の ●v をドラッグしても変えられます。

例 1：標準基底から新しい基底へ

B = 標準基底、B′ = ((1, 1), (−1, 1))。B が標準基底なので

P = 1−111，　P−1 = 1211−11

v = (3, 1) の B′ 座標は x′ = P−131 = 124−2 = 2−1。第3回の例2と一致します。

例 2：どちらも標準基底でないとき

B = ((1, 0), (1, 1)), B′ = ((1, 1), (−1, 1))。

P = B−1B′ = 1−1011−111 = 0−211

列の意味を確かめると、b′1 = 0b1 + 1b2 = (1, 1)、b′2 = −2b1 + b2 = (−1, 1) で正しいです。

例 3：多項式の空間

ℝ[x]2 で B = (1, x, x²), B′ = (1, x − 1, (x − 1)²)。新しい基底を古い基底で表すと

1= 1 · 1 + 0 · x + 0 · x²x − 1= −1 · 1 + 1 · x + 0 · x²(x − 1)²= 1 · 1 − 2 · x + 1 · x²

係数を列に並べて P = 1−1101−2001。x² の B 座標は (0, 0, 1)、B′ 座標は x² = 1 + 2(x − 1) + (x − 1)² より (1, 2, 1) です。

確認：P121 = 1 − 2 + 12 − 21 = 001 となり、x = Px′ が成り立っています。

例 4：基底変換を2回続けると

B → B′ の変換行列が P、B′ → B″ の変換行列が Q なら、B → B″ の変換行列は PQ です。また B′ → B の変換行列は P−1 です。

理由：(B″) = (B′)Q = (B)PQ。

4. よくある間違い

基底が P で変わるので、座標も x′ = Px で変わる。

座標は逆向きに変わります：x = Px′、つまり x′ = P−1x。ものさしを2倍の長さにすると、測った数値は半分になるのと同じです。

b′j の係数を P の第 j 行に並べる。

第 j 列に並べます。(b′1 ⋯ b′n) = (b1 ⋯ bn)P を成分で書くと列になることを確認しましょう。

ℝⁿ で P = B′B−1 と計算する。

B′ = BP から P = B−1B′ です。行列のかけ算は順番を変えられません。

答えが合っているか不安でも、そのまま提出する。

検算は簡単です。Px′ を計算して x に戻るか、または x′1b′1 + ⋯ + x′nb′n が元のベクトルになるかを確かめましょう。

5. 練習問題

問題 1

ℝ² の標準基底 B から B′ = ((2, 1), (1, 1)) への変換行列 P を求め、v = (3, 2) の B′ に関する座標を求めてください。

解答を見る
P = 2111，　det P = 1，　P−1 = 1−1−12
x′ = P−132 = 11

確認：1 · (2, 1) + 1 · (1, 1) = (3, 2)。

問題 2

ℝ² の基底 B = ((1, 1), (1, 2)) から B′ = ((1, 0), (1, −1)) への変換行列 P を求めてください。また、B に関する座標が (1, 1) であるベクトルの、B′ に関する座標を求めてください。

解答を見る
P = B−1B′ = 2−1−11110−1 = 23−1−2

列の確認：2b1 − b2 = (1, 0) = b′1、3b1 − 2b2 = (1, −1) = b′2。

det P = −4 + 3 = −1 より P−1 = 23−1−2（この P はたまたま P−1 = P）。

x′ = P−111 = 5−3

確認：ベクトルは b1 + b2 = (2, 3)。5(1, 0) − 3(1, −1) = (2, 3) で一致します。

問題 3

ℝ[x]1 の基底 B = (1, x) から B′ = (1 + x, 1 − x) への変換行列を求め、3 + 5x の B′ に関する座標を求めてください。

解答を見る

1 + x = 1 · 1 + 1 · x、1 − x = 1 · 1 − 1 · x なので

P = 111−1，　P−1 = 12111−1
x′ = P−135 = 128−2 = 4−1

確認：4(1 + x) − (1 − x) = 3 + 5x。
