第1回

線形空間と部分空間

「足し算」と「実数倍」ができる集まりを、まとめて線形空間と呼びます。矢印だけでなく、多項式・関数・行列も同じ仲間として扱えるようになります。

この回のポイント（まずここだけ押さえましょう）
  1. 線形空間＝「足し算」と「実数倍」が自由にできる集まり。多項式・関数・行列も「ベクトル」の仲間です。
  2. 部分空間かどうかは3条件で判定：(S1) 0 を含む、(S2) 足しても外に出ない、(S3) 実数倍しても外に出ない。
  3. 「部分空間である」は文字を使って証明、「部分空間でない」は反例を1つ挙げれば示せます。

1. 何の話か（直感）

高校では、ベクトルを「向きと大きさをもつ矢印」として学びました。しかし線形代数で大事なのは、矢印の形そのものではなく、次の2つの操作ができることです。

  • 足し算：2つのものを足すと、同じ種類のものになる
  • 実数倍（スカラー倍）：実数をかけると、同じ種類のものになる

たとえば多項式 1 + 2x と 3 − x は、足すと 4 + x、2倍すると 2 + 4x になります。これは係数を並べたベクトル (1, 2)、(3, −1) の計算とまったく同じです。

そこで「足し算とスカラー倍が、いつもの計算規則を満たす集合」を線形空間（ベクトル空間）と呼び、その要素をすべてベクトルと呼ぶことにします。こうしておけば、ℝ² で成り立つ定理が、多項式や関数にもそのまま使えるようになります。

さらに、線形空間の中にある「小さな線形空間」を部分空間といいます。ℝ² の中では、原点を通る直線が代表例です。原点を通らない直線や、半分だけの領域は部分空間になりません。その理由を、下の定義と「動かしてみよう」で確かめます。

2. 定義

定義 1（線形空間）

足し算とスカラー倍ができて、ふだんの計算ルール（交換法則・分配法則など）がそのまま使える集合です。8条件は「いつもの計算ができる」ことを細かく書いたものなので、丸暗記より意味をつかむことを優先しましょう。

集合 V に、和 u + v ∈ V とスカラー倍 cv ∈ V（c ∈ ℝ）が定められていて、すべての u, v, w ∈ V、c, d ∈ ℝ について次の8条件が成り立つとき、V を（ℝ 上の）線形空間といいます。

(V1)(u + v) + w = u + (v + w)　（結合法則） (V2)u + v = v + u　（交換法則） (V3)v + 0 = v となる零ベクトル 0 ∈ V が存在する (V4)各 v に対し v + (−v) = 0 となる逆ベクトル −v ∈ V が存在する (V5)c(u + v) = cu + cv (V6)(c + d)v = cv + dv (V7)(cd)v = c(dv) (V8)1v = v

教科書によっては零ベクトルを o と書きます。このページでは 0 と書きますが、同じものです。

和とスカラー倍の結果がまた V に入ること（V の中で「閉じている」こと）も、定義の前提に含まれています。

定義 2（部分空間）

大きな線形空間の中にあって、それだけで線形空間になっている部分です。

線形空間 V の部分集合 W が、V と同じ和・スカラー倍によってそれ自身線形空間になるとき、W を V の部分空間といいます。

8条件を毎回すべて確かめるのは大変です。しかし (V1)(V2)(V5)〜(V8) は V で成り立っているので、W でも自動的に成り立ちます。確かめるべきなのは次の3つだけです。

定理（部分空間の判定：3条件）

原点（0）を含み、足しても実数倍しても外に出なければ部分空間です。

V の部分集合 W が部分空間であるための必要十分条件は、次の3つが成り立つことです。

(S1)0 ∈ W　（零ベクトルを含む） (S2)u, v ∈ W ならば u + v ∈ W　（和で閉じている） (S3)u ∈ W, c ∈ ℝ ならば cu ∈ W　（スカラー倍で閉じている）

(S3) で c = −1 とすれば逆ベクトルが W に入るので (V4) も成り立ちます。

判定の進め方
  • 部分空間であることを示すとき：任意の u, v, c について (S1)〜(S3) を文字で証明します。
  • 部分空間でないことを示すとき：(S1)〜(S3) のどれかが崩れる具体例（反例）を1つ挙げれば十分です。

3. 具体例

例 1：数ベクトル空間 ℝⁿ

n 個の実数の組全体 ℝⁿ = { (x1, …, xn) | xi ∈ ℝ } は、成分ごとの和とスカラー倍で線形空間になります。零ベクトルは (0, …, 0) です。

x1⋮xn + y1⋮yn = x1 + y1⋮xn + yn，　c x1⋮xn = cx1⋮cxn
例 2：多項式の空間 ℝ[x]n

n 次以下の実数係数の多項式全体を ℝ[x]n と書きます。

ℝ[x]2 = { a + bx + cx² | a, b, c ∈ ℝ }

2次以下どうしを足しても、実数倍しても2次以下なので、ℝ[x]2 は線形空間です。零ベクトルは多項式 0（すべての係数が 0）です。

注意：「ちょうど2次の多項式全体」は線形空間になりません。x² + (−x² + x) = x は2次ではないからです（和で閉じていない）。

例 3：関数の空間

実数全体で定義された実数値関数全体を F(ℝ) とします。和とスカラー倍を

(f + g)(x) = f(x) + g(x)，　(cf)(x) = c · f(x)

と「各点ごと」に定めると、F(ℝ) は線形空間です。零ベクトルは恒等的に 0 の関数 o(x) = 0 です。sin x や ex も、この空間の「ベクトル」です。

例 4：行列の空間 Mm,n(ℝ)

m × n 実行列全体は、成分ごとの和とスカラー倍で線形空間です。零ベクトルは零行列 O です。

1234 + 0−152 = 1186，　31234 = 36912
例 5：部分空間であることの証明

W = { x ∈ ℝ³ | x1 + 2x2 − x3 = 0 } は ℝ³ の部分空間です（原点を通る平面）。

  • (S1)　0 + 2·0 − 0 = 0 なので 0 ∈ W。
  • (S2)　x, y ∈ W とすると (x1+y1) + 2(x2+y2) − (x3+y3) = (x1+2x2−x3) + (y1+2y2−y3) = 0 + 0 = 0。よって x + y ∈ W。
  • (S3)　cx1 + 2cx2 − cx3 = c(x1+2x2−x3) = c · 0 = 0。よって cx ∈ W。

同じ議論で、同次連立1次方程式 Ax = 0 の解全体はいつも部分空間になります（解空間）。

例 6：部分空間でないことの証明（反例を1つ）
  • W = { (x, y) | x + y = 1 }：(0, 0) は 0 + 0 ≠ 1 なので 0 ∉ W。(S1) が不成立。
  • W = { (x, y) | xy = 0 }（2本の座標軸）：(1, 0), (0, 1) ∈ W ですが、和 (1, 1) は 1·1 ≠ 0 なので W に入りません。(S2) が不成立。
  • W = { (x, y) | x ≥ 0, y ≥ 0 }（第1象限）：(1, 1) ∈ W ですが、(−1)·(1, 1) = (−1, −1) ∉ W。(S3) が不成立。

4. よくある間違い

0 ∈ W を確かめたので、W は部分空間である。

(S1) は必要条件の1つにすぎません。xy = 0 の集合は原点を含みますが、和で閉じていないので部分空間ではありません。3条件すべてが必要です。

(1, 2) と (2, 4) を足したら (3, 6) で、W に入ったので「和で閉じている」。

「閉じている」ことは任意の u, v について示す必要があります。具体例でうまくいっても証明になりません。文字でおいて計算しましょう。一方、閉じていないことは反例1つで示せます。

関数の空間の零ベクトルは「数の 0」である。

零ベクトルはその空間の要素です。関数の空間なら恒等的に 0 の関数、行列の空間なら零行列 O、多項式の空間なら多項式 0 です。

「ちょうど n 次の多項式全体」も線形空間である。

零多項式を含まず、和で次数が下がることもあるので線形空間ではありません。線形空間になるのは「n 次以下」の多項式全体 ℝ[x]n です。

第1象限は和で閉じているので部分空間である。

スカラー倍は負の数もかけます。(S3) で c = −1 を試すと外に出るので、部分空間ではありません。

5. 練習問題

解き方の手順：部分空間かどうかの判定
  1. まず 0 が W に入るか確かめます。入らなければ、その時点で「部分空間でない」と結論できます。
  2. 条件が「1次式 = 0」の形（定数項・2乗・積・不等号・「整数」などがない）なら、部分空間である見込みが高いです。u, v を文字でおいて (S2)(S3) を証明します。
  3. 不等号・2乗・積・「整数」などがあれば、反例を探します。−1 倍、12 倍、2つのベクトルの和を試すと見つかりやすいです。
問題 1 教科書 練習問題4 [A] 5 の類題

次の ℝ³ の部分集合は部分空間になるか判定してください。

(1) W1 = { x | x1 + x3 = 0 }　(2) W2 = { x | x1 ≥ x2 }
(3) W3 = { x | x1 = 2x3 }　(4) W4 = { x | x1, x2, x3 は整数 }

解答を見る

(1) 部分空間です。(S1) 0 + 0 = 0。(S2) x, y ∈ W1 なら (x1 + y1) + (x3 + y3) = (x1 + x3) + (y1 + y3) = 0。(S3) cx1 + cx3 = c(x1 + x3) = 0。

(2) 部分空間ではありません。(1, 0, 0) ∈ W2（1 ≥ 0）ですが、(−1) · (1, 0, 0) = (−1, 0, 0) は −1 ≥ 0 を満たさないので W2 に入りません（スカラー倍で閉じていない）。

(3) 部分空間です。(S1) 0 = 2·0。(S2) x1 + y1 = 2x3 + 2y3 = 2(x3 + y3)。(S3) cx1 = c · 2x3 = 2(cx3)。

(4) 部分空間ではありません。和では閉じていますが、(1, 0, 0) ∈ W4 に実数 12 をかけた (12, 0, 0) は W4 に入りません。スカラーはすべての実数をとることに注意しましょう。

問題 2 教科書 練習問題4 [B] 4 の類題

2次の実行列全体 M2 の次の部分集合は、部分空間になるか判定してください。

(1) W1 = { A | tA = −A }（交代行列）　(2) W2 = { A | A² = O }　(3) W3 = { A | tr A = 0 }

解答を見る

(1) 部分空間です。(S1) tO = O = −O。(S2) t(A + B) = tA + tB = −A − B = −(A + B)。(S3) t(cA) = c tA = −cA。

(2) 部分空間ではありません。A = 0100, B = 0010 はどちらも 2乗すると O ですが、

(A + B)² = 0110² = 1001 ≠ O

なので和で閉じていません。

(3) 部分空間です。tr O = 0。tr(A + B) = tr A + tr B = 0、tr(cA) = c tr A = 0。

問題 3 教科書 練習問題4 [B] 9 の類題

B を n 次行列とするとき、AB = BA を満たす n 次行列 A の全体 W は、n 次行列全体のつくる線形空間 Mn の部分空間であることを示してください。

解答を見る
  • (S1)　OB = O = BO なので O ∈ W。
  • (S2)　A1, A2 ∈ W なら (A1 + A2)B = A1B + A2B = BA1 + BA2 = B(A1 + A2)。
  • (S3)　(cA)B = c(AB) = c(BA) = B(cA)。

よって W は部分空間です。行列の分配法則とスカラー倍の性質だけで示せることを確認しましょう。

1次独立と1次従属

ベクトルの組に「むだ」があるかどうかを判定します。むだのない組を1次独立、むだのある組を1次従属といいます。判定は同次連立1次方程式を解くことに帰着します。

1. 何の話か（直感）

ベクトルをいくつか持っているとき、「その中のどれかが、ほかのベクトルの組み合わせで作れてしまう」なら、そのベクトルはむだです。持っていなくても、同じものが作れるからです。

  • ℝ² の2本のベクトルが同一直線上にあると、片方はもう片方の定数倍です。2本あっても「1方向」にしか進めません。
  • ℝ³ の3本のベクトルが同一平面上にあると、どれか1本は残り2本の組み合わせで作れます。3本あっても「平面」の中しか動けません。

むだがない状態を1次独立、むだがある状態を1次従属といいます。図で言えば、ℝ² では2本が作る平行四辺形の面積、ℝ³ では3本が作る平行六面体の体積が 0 になるかどうかです。下の「動かしてみよう」で、ベクトルを動かして確かめてください。

2. 定義

定義（1次結合・1次関係）

ベクトル a1, …, ak と実数 c1, …, ck に対し、c1a1 + ⋯ + ckak を1次結合（線形結合）といいます。また

c1a1 + c2a2 + ⋯ + ckak = 0　　(★)

の形の式を1次関係といいます。c1 = ⋯ = ck = 0 なら (★) はいつも成り立ちます（自明な1次関係）。

定義（1次独立・1次従属）

「係数を全部 0 にする以外に、足して 0 にする方法がない」のが独立、「ほかにもある」のが従属です。

  • (★) を満たす (c1, …, ck) が c1 = ⋯ = ck = 0 しかないとき、a1, …, ak は1次独立であるといいます。
  • 少なくとも1つは 0 でない (c1, …, ck) で (★) が成り立つとき、1次従属であるといいます。
定理 1（従属の言いかえ）

a1, …, ak が1次従属 ⇔ どれか1つのベクトルが、残りのベクトルの1次結合で書ける。

理由：cj ≠ 0 なら (★) を cj で割って移項すると aj = −Σi≠j (ci/cj) ai となります。

定理 2（連立方程式による判定）

ベクトルを列に並べて簡約化し、ピボットが本数ぶんあれば独立です。

a1, …, ak ∈ ℝⁿ を列に並べた n × k 行列を A = (a1 ⋯ ak) とすると、(★) は同次連立1次方程式 Ac = 0（c = t(c1, …, ck)）です。よって

1次独立　⇔　Ac = 0 の解が c = 0 だけ　⇔　rank A = k
  • k = n（正方行列）のときは：1次独立 ⇔ det A ≠ 0（教科書の記号では |A| ≠ 0）
  • k > n のときは：rank A ≤ n < k なので必ず1次従属

3. 具体例

例 1：ℝ² の2本（従属）

a1 = (1, 2), a2 = (2, 4) は a2 = 2a1 なので、2a1 − a2 = 0 という自明でない1次関係があります。よって1次従属です。実際 det 1224 = 4 − 4 = 0。

例 2：ℝ³ の3本（独立）

a1 = (1, 1, 0), a2 = (0, 1, 1), a3 = (1, 0, 1)。c1a1 + c2a2 + c3a3 = 0 を成分で書くと

c1 + c3= 0c1 + c2= 0c2 + c3= 0

1式目と2式目から c3 = −c1, c2 = −c1。3式目に入れると −2c1 = 0 より c1 = 0、したがって c1 = c2 = c3 = 0。1次独立です（det = 2 ≠ 0 でも確認できます）。

例 3：ℝ³ の3本（従属）— 行基本変形で判定

a1 = (1, 2, 3), a2 = (2, −1, 1), a3 = (3, 1, 4) を列に並べて簡約化します。

A = 1232−11314 → 1230−5−50−5−5 → 101011000

rank A = 2 < 3 なので1次従属です。最後の行列から c1 = −t, c2 = −t, c3 = t。t = 1 として −a1 − a2 + a3 = 0、つまり a3 = a1 + a2（3本は同一平面上）です。

基底・次元・座標

基底は空間の「ものさし（座標軸）」の選び方、次元はそのものさしの本数です。同じベクトルでも、基底を変えると座標の数値が変わります。

1. 何の話か（直感）2. 定義3. 具体例4. よくある間違い5. 練習問題▶ 動かしてみよう
この回のポイント（まずここだけ押さえましょう）
  1. 基底＝「1次独立」かつ「全体を生成する」ベクトルの組。空間の「ものさし（座標軸）」です。
  2. 次元＝基底のベクトルの本数。どの基底を選んでも同じ数になります。
  3. 座標は基底によって変わります。座標を求めることは、x1b1 + ⋯ + xnbn = v を解くことです。

1. 何の話か（直感）

平面上の点を (3, 1) のように2つの数で表せるのは、「x 方向に1目盛り」「y 方向に1目盛り」という2本のものさし e1 = (1, 0), e2 = (0, 1) を決めているからです。

しかし、ものさしは斜めでも、長さがばらばらでも構いません。条件は次の2つだけです。

  • むだがない（1次独立）：どのものさしも、ほかのものさしで代用できない
  • 足りている（生成する）：空間のどのベクトルも、ものさしの組み合わせで表せる

この2条件を満たすものさしの組を基底、その本数を次元といいます。ℝ² の基底はどう選んでも必ず2本です。そして、ベクトルを基底の組み合わせで表したときの係数が座標です。同じ矢印でも、ものさしを変えれば座標は変わります。下の図で確かめましょう。

2. 定義

定義 1（生成する部分空間）

a1, …, ak の1次結合全体

⟨a1, …, ak⟩ = { c1a1 + ⋯ + ckak | ci ∈ ℝ }

は部分空間です。これを a1, …, ak が生成する（張る）部分空間といいます。V = ⟨a1, …, ak⟩ のとき、a1, …, ak は V を生成するといいます。

定義 2（基底）

「むだがない（1次独立）」かつ「足りている（生成する）」ベクトルの組です。

線形空間 V のベクトルの組 (b1, …, bn) が次の2条件を満たすとき、V の基底といいます。

(B1)b1, …, bn は1次独立である (B2)b1, …, bn は V を生成する
定理 1（次元）

空間の中を「自由に動ける方向の数」が次元です。基底の選び方を変えても変わりません。

V の基底に含まれるベクトルの本数は、基底の選び方によらず一定です。この本数を V の次元といい、dim V と書きます。ただし dim { 0 } = 0 と約束します。

定義 3（座標）

v を基底で表したときの係数の組です。基底を変えると座標も変わります。

(b1, …, bn) を V の基底とすると、各 v ∈ V は

v = x1b1 + x2b2 + ⋯ + xnbn

とただ1通りに表せます。この係数を並べた t(x1, …, xn) ∈ ℝⁿ を、基底に関する v の座標（座標ベクトル）といいます。

1通りである理由：2通り Σxibi = Σyibi に書けたとすると Σ(xi − yi)bi = 0。1次独立なので xi = yi。

定理 2（次元がわかっているとき）

dim V = n とします。V の n 本のベクトルについて、

1次独立である　⇔　V を生成する　⇔　基底である

つまり本数が次元と一致していれば、(B1) と (B2) の片方を確かめるだけで基底だとわかります。特に ℝⁿ の n 本は「列に並べた行列の行列式 ≠ 0」なら基底です。

3. 具体例

例 1：ℝⁿ の標準基底

e1 = (1, 0, …, 0), …, en = (0, …, 0, 1) は ℝⁿ の基底（標準基底）で、dim ℝⁿ = n。標準基底に関する座標は、ベクトルの成分そのものです。

例 2：ℝ² の別の基底と座標

b1 = (1, 1), b2 = (−1, 1) は det 1−111 = 2 ≠ 0 なので基底です（定理2）。v = (3, 1) の座標を求めるには x1b1 + x2b2 = v を解きます。

x1 − x2= 3x1 + x2= 1　⇒　x1 = 2,　x2 = −1

(1, 0), (0, 1), (1, 1) は ℝ² を生成するので基底である。

生成はしますが、(1, 1) = (1, 0) + (0, 1) なので1次独立ではありません。基底は独立かつ生成の両方が必要です。ℝ² の基底は必ず2本です。

ベクトル (3, 1) の座標は、どんな基底でも (3, 1) である。

座標を考えるときの基底は順番つきです。順番を入れ替えると座標の成分も入れ替わります。

式は自由度を減らすものです。独立な式が1本なら dim W = 3 − 1 = 2。基底を実際に求めて本数を数えるのが確実です。

零空間 { 0 } の基底は 0 なので、次元は 1。

0 だけの組は1次従属なので基底になれません。{ 0 } の基底は空集合で、dim { 0 } = 0 です。

基底変換と座標変換

同じベクトルを2種類の基底で測ると、座標の数値が変わります。その「換算表」が変換行列 P です。P の作り方と、座標の変換公式 x = Px′ を学びます。

1. 何の話か（直感）2. 定義3. 具体例4. よくある間違い5. 練習問題▶ 動かしてみよう
この回のポイント（まずここだけ押さえましょう）
  1. 変換行列 P の第 j 列＝新しい基底 b′j を古い基底で表した係数です。
  2. 座標は逆向きに変わります：x = Px′（つまり x′ = P−1x）。
  3. ℝⁿ では P = B−1B′。実際には [B | B′] を簡約化すると右側に P が出てきます。

1. 何の話か（直感）

長さを「メートル」で測るか「フィート」で測るかで数値が変わるように、ベクトルも基底（ものさし）を変えると座標の数値が変わります。第3回で見たとおり、v = (3, 1) は標準基底では (3, 1)、基底 ((1, 1), (−1, 1)) では (2, −1) でした。

基底を変えるたびに連立方程式を解くのは大変です。そこで、

  1. 「新しい基底の各ベクトルを、古い基底で表すと何か」を1つの行列 P（基底の変換行列）にまとめておき、
  2. 座標の換算は行列のかけ算 x = Px′ で済ませる

というのが今回の話です。ポイントは、基底は P で「古い→新しい」に変わるのに、座標は逆向きの式になることです。下の計算機で確かめてみましょう。

用語メモ
基底変換きていへんかん
使う基底を、別の基底に取りかえること。
変換行列 Pへんかんぎょうれつ
新しい基底を古い基底で表したときの係数を、列に並べた行列。

2. 定義

線形空間 V の2組の基底を B = (b1, …, bn)（古い基底）、B′ = (b′1, …, b′n)（新しい基底）とします。

定義（基底の変換行列）

新しいものさしを、古いものさしで測った数値を列に並べた表です。

新しい基底の各ベクトルを古い基底の1次結合で表します。

b′j = p1jb1 + p2jb2 + ⋯ + pnjbn　　(j = 1, …, n)

この係数を第 j 列に並べた n 次正方行列 P = (pij) を、B から B′ への基底の変換行列といいます。まとめて書くと

(b′1 ⋯ b′n) = (b1 ⋯ bn) P

つまり P の第 j 列 = b′j の B に関する座標 です。P は必ず正則です。

定理（座標変換の公式）

「新しい座標 x′ に P をかけると古い座標 x になる」と覚えましょう。逆向き（古い→新しい）は P−1 です。

v ∈ V の B に関する座標を x、B′ に関する座標を x′ とすると

x = Px′，　　x′ = P−1x

証明：v = (b′1 ⋯ b′n)x′ = (b1 ⋯ bn)Px′。一方 v = (b1 ⋯ bn)x。座標はただ1通りなので x = Px′。

ℝⁿ での求め方

V = ℝⁿ なら、基底のベクトルを列に並べた行列を同じ記号 B, B′ で表すと、B′ = BP なので

P = B−1B′

線形写像

「和」と「スカラー倍」を保つ写像を線形写像といいます。平面では、方眼を「平行で等間隔な方眼」に移し、原点を動かさない変換です。

1. 何の話か（直感）

線形空間は「足し算とスカラー倍ができる世界」でした。その構造をこわさずに、ある線形空間から別の線形空間へベクトルを移す写像が線形写像です。

平面 ℝ² から ℝ² への線形写像を図で見ると、次のような特徴があります。

  • 原点は原点に移る
  • 直線は直線に、平行な線は平行な線に、等間隔な目盛りは等間隔な目盛りに移る
  • だから、e1 = (1, 0) と e2 = (0, 1) の行き先さえわかれば、平面全体の行き先が決まる

e1, e2 の行き先を列に並べたものが行列です。下の図で行列の成分を変えて、方眼がどう変形するか見てみましょう。

2. 定義

定義（線形写像）

「足してから写しても、写してから足しても同じ」「何倍かしてから写しても、写してから何倍かしても同じ」という写像です。

V, W を線形空間とします。写像 f : V → W が、すべての u, v ∈ V、c ∈ ℝ について

(L1)f(u + v) = f(u) + f(v)　（和を保つ） (L2)f(cu) = c f(u)　（スカラー倍を保つ）

を満たすとき、f を線形写像といいます。V = W のときは線形変換ともいいます。

定理 1（基本性質）

f が線形写像なら

  • f(0) = 0　（(L2) で c = 0 とする）
  • f(c1v1 + ⋯ + ckvk) = c1f(v1) + ⋯ + ckf(vk)　（1次結合を保つ）
定理 2（ℝⁿ → ℝᵐ の線形写像は行列）

e1, e2, … の行き先を列に並べれば、それがその写像の行列です。

f : ℝⁿ → ℝᵐ が線形写像なら、m × n 行列

A = ( f(e1)　f(e2)　⋯　f(en) )

を使って f(x) = Ax と書けます。逆に、行列 A で定まる写像 x ↦ Ax はいつも線形写像です。

理由：x = x1e1 + ⋯ + xnen に定理1を使うと f(x) = x1f(e1) + ⋯ + xnf(en) = Ax。

f(x) = 2x + 3 は1次関数なので線形写像である。

(1, 2) と (3, 4) で (L1) が成り立ったので、線形写像である。

像と核・次元定理

線形写像で「実際に届く先」が像 Im f、「0 につぶれるもの」が核 Ker f です。両者の次元の間には、次元定理という美しい関係があります。

1. 何の話か（直感）2. 定義3. 具体例4. よくある間違い5. 練習問題▶ 動かしてみよう
この回のポイント（まずここだけ押さえましょう）
  1. 像 Im f＝実際に出てくる出力全体（値域の中）。核 Ker f＝0 に写るもの全体（定義域の中）。
  2. 簡約化でピボットのある列を探します。Im の基底は「元の A」のピボット列、Ker の基底は自由変数から作ります。

1. 何の話か（直感）

線形写像 f : V → W について、次の2つの集合を考えます。

  • 像 Im f：f の出力として実際に出てくるベクトル全体（行き先側 W の中にある）。「f でどこまで届くか」を表します。
  • 核 Ker f：f で0 につぶされるベクトル全体（出発側 V の中にある）。「f で何が消えるか」を表します。

たとえば ℝ² を x 軸に真上から影を落とす写像 f(x, y) = (x, 0) では、像は x 軸、核は y 軸です。2次元のうち「1次元ぶんが消えて、1次元ぶんが残った」と見ることができます。

これを一般化したのが次元定理 dim V = dim Ker f + dim Im f です。入力の次元は「消える分」と「残る分」に分かれます。

2. 定義

定義（像と核）

像は「どこまで届くか」、核は「何が 0 につぶされるか」を表す集合です。

線形写像 f : V → W に対して

Im f= { f(v) | v ∈ V }　⊂ W　（像）Ker f= { v ∈ V | f(v) = 0 }　⊂ V　（核）

Im f は W の部分空間、Ker f は V の部分空間です。

定理 1（行列で表される場合）

m × n 行列 A = (a1 ⋯ an) で f(x) = Ax（f : ℝⁿ → ℝᵐ）のとき

  • Im f = ⟨a1, …, an⟩（A の列ベクトルが生成する空間）、dim Im f = rank A
  • Ker f = 同次連立方程式 Ax = 0 の解空間、dim Ker f = n − rank A
定理 2（次元定理）

入力の次元 ＝ つぶれて消える次元 ＋ 残る次元、ということです。

V が有限次元のとき、線形写像 f : V → W について

dim V = dim Ker f + dim Im f

系：f が単射 ⇔ Ker f = { 0 }。m × n 行列 A で表されるときは、単射 ⇔ rank A = n、全射 ⇔ rank A = m。

求め方（f(x) = Ax のとき）
  1. A を行基本変形で簡約化（階段行列に）し、ピボット（各行の先頭の 1）がある列を調べる。
  2. Im の基底：ピボット列と同じ番号の、元の A の列ベクトル。
  3. Ker の基底：ピボットのない列の変数を自由変数（パラメータ）として Ax = 0 を解き、パラメータごとのベクトルを取り出す。

  • Ker f：x1 + 2x2 = 0。x2 = t とおくと x = t(−2, 1)。基底 (−2, 1)、dim Ker f = 1。
  • 次元定理：2 = 1 + 1 ✓

  • Ker f：自由変数 x2 = s, x4 = t。x1 = −2s − t, x3 = −2t より

表現行列

線形写像を、基底を決めて「座標の計算」に翻訳したものが表現行列です。作り方の3ステップと、基底を変えたときの公式 A′ = Q⁻¹AP を学びます。

1. 何の話か（直感）2. 定義3. 具体例4. よくある間違い5. 練習問題▶ 動かしてみよう
この回のポイント（まずここだけ押さえましょう）
  1. 表現行列の第 j 列＝ f(vj) を値域の基底 C で表した座標です。
  2. 作り方は3ステップ：①行き先 f(vj) を計算 → ② C で表す → ③ 列に並べる。
  3. 基底を変えると A′ = Q−1AP（両側で同じ基底なら P−1AP）。うまい基底を選ぶと対角行列になります。

1. 何の話か（直感）

ℝⁿ → ℝᵐ の線形写像は行列のかけ算で書けました（第5回）。では、微分 D : ℝ[x]2 → ℝ[x]1 のように、ベクトルが数の組でない場合はどうでしょうか。

答えは、基底を決めて座標で考えることです。基底を決めれば、どんな有限次元の線形空間のベクトルも「座標＝数の組」で表せます（第3回）。すると線形写像は「座標を座標に移す写像」になり、それは行列で書けます。この行列が表現行列です。

V の v─ f で写す →W の f(v)↓ 基底 B で
座標にする↓ 基底 C で
座標にする座標 x ∈ ℝⁿ─ A をかける →座標 Ax ∈ ℝᵐ

上の道（f で写してから座標にする）と下の道（座標にしてから A をかける）が同じ結果になる A が、表現行列です。

大事なのは、同じ写像でも基底の選び方で表現行列が変わることです。うまい基底を選ぶと、表現行列が対角行列のような簡単な形になります。これが次の単元「固有値・対角化」につながります。

2. 定義

f : V → W を線形写像、B = (v1, …, vn) を V の基底、C = (w1, …, wm) を W の基底とします。

定義（表現行列）

「vj がどこへ行くか」を、行き先側のものさし C で測った数値を列に並べた表です。

各 f(vj) を C の1次結合で表します。

f(vj) = a1jw1 + a2jw2 + ⋯ + amjwm　　(j = 1, …, n)

この係数を第 j 列に並べた m × n 行列 A = (aij) を、基底 B, C に関する f の表現行列といいます。まとめて書くと

( f(v1) ⋯ f(vn) ) = ( w1 ⋯ wm ) A
作り方の3ステップ
  1. 定義域の基底の各ベクトル vj の行き先 f(vj) を計算する。
  2. f(vj) を値域の基底 C で表したときの座標を求める。
  3. その座標を第 j 列に並べる。
定理 1（座標で見た f）

v の B 座標を x とすると、f(v) の C 座標は Ax です。

ℝⁿ → ℝᵐ で f(x) = Mx（M は標準基底での行列）、基底のベクトルを列に並べた行列を B, C とすると A = C−1MB。

定理 2（基底を変えたときの表現行列）

右の P で「新しい座標→古い座標」に直し、A で写し、左の Q−1 で「行き先の古い座標→新しい座標」に直す、という3段階をまとめた式です。

V の基底を B → B′（変換行列 P）、W の基底を C → C′（変換行列 Q）に取りかえると、新しい表現行列は

A′ = Q−1AP

特に V = W で、両側で同じ基底を使う（B = C, B′ = C′）なら A′ = P−1AP。

理由：B′ 座標 x′ → B 座標 Px′ → f で C 座標 APx′ → C′ 座標 Q−1APx′（第4回の座標変換の公式）。
