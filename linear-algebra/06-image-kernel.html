像と核・次元定理

線形写像で「実際に届く先」が像 Im f、「0 につぶれるもの」が核 Ker f です。両者の次元の間には、次元定理という美しい関係があります。

1. 何の話か（直感）

線形写像 f : V → W について、次の2つの集合を考えます。

  • 像 Im f：f の出力として実際に出てくるベクトル全体（行き先側 W の中にある）。「f でどこまで届くか」を表します。
  • 核 Ker f：f で0 につぶされるベクトル全体（出発側 V の中にある）。「f で何が消えるか」を表します。

たとえば ℝ² を x 軸に真上から影を落とす写像 f(x, y) = (x, 0) では、像は x 軸、核は y 軸です。2次元のうち「1次元ぶんが消えて、1次元ぶんが残った」と見ることができます。

これを一般化したのが次元定理 dim V = dim Ker f + dim Im f です。入力の次元は「消える分」と「残る分」に分かれます。

2. 定義

定義（像と核）

線形写像 f : V → W に対して

Im f= { f(v) | v ∈ V }　⊂ W　（像）Ker f= { v ∈ V | f(v) = 0 }　⊂ V　（核）

Im f は W の部分空間、Ker f は V の部分空間です。

定理 1（行列で表される場合）

m × n 行列 A = (a1 ⋯ an) で f(x) = Ax（f : ℝⁿ → ℝᵐ）のとき

  • Im f = ⟨a1, …, an⟩（A の列ベクトルが生成する空間）、dim Im f = rank A
  • Ker f = 同次連立方程式 Ax = 0 の解空間、dim Ker f = n − rank A
定理 2（次元定理）

V が有限次元のとき、線形写像 f : V → W について

dim V = dim Ker f + dim Im f

系：f が単射 ⇔ Ker f = { 0 }。m × n 行列 A で表されるときは、単射 ⇔ rank A = n、全射 ⇔ rank A = m。

求め方（f(x) = Ax のとき）
  1. A を行基本変形で簡約化（階段行列に）し、ピボット（各行の先頭の 1）がある列を調べる。
  2. Im の基底：ピボット列と同じ番号の、元の A の列ベクトル。
  3. Ker の基底：ピボットのない列の変数を自由変数（パラメータ）として Ax = 0 を解き、パラメータごとのベクトルを取り出す。

3. 具体例

例 1：2 × 2（つぶれる場合）

A = 1224 → 1200（簡約化）。ピボットは第1列だけなので rank A = 1。

  • Im f の基底：元の第1列 (1, 2)。dim Im f = 1。
  • Ker f：x1 + 2x2 = 0。x2 = t とおくと x = t(−2, 1)。基底 (−2, 1)、dim Ker f = 1。
  • 次元定理：2 = 1 + 1 ✓
例 2：3 × 4
A = 120124141213 → 120100120012 → 120100120000

ピボットは第1列と第3列なので rank A = 2。

  • Im f の基底：元の A の第1列・第3列 (1, 2, 1), (0, 1, 1)。dim Im f = 2。
  • Ker f：自由変数 x2 = s, x4 = t。x1 = −2s − t, x3 = −2t より
    x = s−2100 + t−10−21
    基底はこの2本、dim Ker f = 2。
  • 次元定理：4 = 2 + 2 ✓

確認：A(−1, 0, −2, 1) の各成分は −1 + 0 + 0 + 1 = 0、−2 + 0 − 2 + 4 = 0、−1 + 0 − 2 + 3 = 0。

例 3：微分

D : ℝ[x]2 → ℝ[x]2, D(f) = f ′。微分して 0 になるのは定数なので Ker D = ⟨1⟩（dim 1）。(a + bx + cx²)′ = b + 2cx なので Im D = ⟨1, x⟩ = ℝ[x]1（dim 2）。3 = 1 + 2 ✓

例 4：正則行列

A が n 次正則行列なら rank A = n。Ker f = { 0 }（dim 0）、Im f = ℝⁿ（dim n）。n = 0 + n ✓

4. よくある間違い

Im f の基底として、簡約化した後の行列の列を答える。

行基本変形で列ベクトルの空間は変わってしまいます。例1では簡約化後の第1列 (1, 0) は Im f = ⟨(1, 2)⟩ に入っていません。ピボットの位置だけを簡約化で調べ、ベクトルは元の A から取ります。

Ker f と Im f は同じ空間の中にある。

A が m × n なら、Ker f ⊂ ℝⁿ（定義域、ベクトルの長さ n）、Im f ⊂ ℝᵐ（値域、長さ m）です。答えのベクトルの長さで確認しましょう。

次元定理の左辺を「行の数 m」にする。

左辺は定義域の次元 = 列の数 n です：n = dim Ker f + rank A。

Ker f = { 0 } のとき、基底は 0、次元は 1。

0 は基底になれません。Ker f = { 0 } の次元は 0 で、基底は「なし」（空集合）です。

5. 練習問題

問題 1 教科書 練習問題5 [A] 4 の類題

次の行列に対応する線形写像の像と核のそれぞれの基底を求めてください。

(1) 2−14　　　(2) 122130
解答を見る

(1) f : ℝ³ → ℝ、rank = 1。

  • Im f = ℝ。基底は (2)（0 でない実数なら何でもよく、1 でも可）。
  • Ker f：2x1 − x2 + 4x3 = 0。x2 = 2x1 + 4x3 なので、x1 = s, x3 = t とおいて x = s(1, 2, 0) + t(0, 4, 1)。基底は (1, 2, 0), (0, 4, 1)。
  • 次元定理：3 = 2 + 1 ✓

(2) f : ℝ² → ℝ³。122130 → 120−30−6 → 100100、rank = 2。

  • Im f の基底：元の列 (1, 2, 3), (2, 1, 0)。
  • Ker f = { 0 }（基底なし、次元 0）。
  • 次元定理：2 = 0 + 2 ✓
問題 2 教科書 練習問題5 [A] 5, 8(1) の類題

次の行列で決まる ℝ⁴ の線形変換 f について、f の像と核のそれぞれの基底および f のランクを求めてください。

A = 12010111131223−11
解答を見る
A → 1201011101110−1−1−1 → 10−2−1011100000000

ピボットは第1・第2列なので rank f = 2。

  • Im f の基底：元の第1・第2列 (1, 0, 1, 2), (2, 1, 3, 3)。
  • Ker f：x3 = s, x4 = t とおくと x1 = 2s + t, x2 = −s − t。基底は (2, −1, 1, 0), (1, −1, 0, 1)。
  • 次元定理：4 = 2 + 2 ✓

3行目 = 1行目 + 2行目、4行目 = 2 × 1行目 − 2行目 になっていることに気づくと、rank 2 がすぐわかります。上の「動かしてみよう」でサイズ 4×4 の例「問題2」を選ぶと確認できます。

問題 3 教科書 練習問題5 [A] 6 の類題

次の行列に対応する線形写像 f は全射であるか、単射であるかを調べてください。

(1) 12013−1　　(2) 11001110−1　　(3) 102011
解答を見る

m × n 行列 A で決まる f : ℝⁿ → ℝᵐ について

  • 単射 ⇔ Ker f = { 0 } ⇔ rank A = n（列の数）
  • 全射 ⇔ Im f = ℝᵐ ⇔ rank A = m（行の数）

(1) 3 × 2、rank = 2（2列が平行でない）。rank = n = 2 なので単射、rank < m = 3 なので全射ではない。

(2) 3 × 3、行列式 1·(−1 − 0) − 1·(0 − 1) + 0 = 0 なので rank = 2。単射でも全射でもない。

(3) 2 × 3、rank = 2。rank = m = 2 なので全射、rank < n = 3 なので単射ではない。
