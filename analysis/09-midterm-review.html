4. 確認クイズ

選択肢をクリックして答えよう

全12問。答えるとすぐに解説が表示されます。

Q1. lim(x, y) → (0, 0)x2x2 + y2 は？

x 軸に沿うと 1、y 軸に沿うと 0。近づき方で値が違うので存在しない。

Q2. f = x2y3 のとき fxy は？

fx = 2xy3 をさらに y で偏微分して 6xy2。

Q3. 「偏微分可能ならば連続」は正しい？

反例 xyx2 + y2（原点で 0）。偏微分可能だが原点で不連続。連続性を保証するのは全微分可能性。

Q4. z = x2 + y2 の点 (1, 1, 2) での接平面は？

z = 2 + 2(x − 1) + 2(y − 1) = 2x + 2y − 2。

Q5. z = f(x, y), x = t2, y = t3 のとき dzdt は？

連鎖律 fxdxdt + fydydt。

Q6. 2次のテイラー多項式で、hk の項の係数は？

12(fxxh2 + 2fxyhk + fyyk2) なので 12 · 2fxy = fxy。

Q7. 勾配 ∇f の向きは？

∇f は最も急に増加する向きで、等高線と直交する。

Q8. f = x2 + 3xy の点 (1, 2) における、u = (0, 1) 方向の方向微分係数は？

u = (0, 1) 方向は fy = 3x = 3。

Q9. 停留点で fxx = 2, fxy = 3, fyy = 4。この点は？

H = 2 · 4 − 32 = −1 < 0 なので鞍点。

Q10. 停留点で fxx = −1, fxy = 0, fyy = −3。この点は？

H = 3 > 0, fxx < 0 なので極大。

Q11. 円 x2 + y2 = 25 の点 (3, 4) での dydx は？

−gxgy = −2x2y = −34。

Q12. 条件 x2 + y2 = 2 のもとでの x + y の最大値は？

1 = 2λx, 1 = 2λy より x = y、x = y =  ± 1。最大値 2（点 (1, 1)）。

5. 総合問題

問題 1 極限・偏微分・全微分

f(x, y) = x3 − y3x2 + y2 ((x, y) ≠ (0, 0)), f(0, 0) = 0 について、(1) 原点で連続か、(2) fx(0, 0), fy(0, 0)、(3) 原点で全微分可能か、を調べてください。

解答を見る

(1) 極座標で |f| = r|cos3θ − sin3θ| ≤ 2r → 0。連続。

(2) fx(0, 0) = limh3/h2h = 1, fy(0, 0) = lim−k3/k2k = −1。

(3) ε = f(h, k) − h + k = h3 − k3 − (h − k)(h2 + k2)h2 + k2 = hk(h − k)h2 + k2。

ε√h2 + k2 = cosθsinθ(cosθ − sinθ) は r によらず、θ = −π4 で −√22 ≠ 0。全微分可能でない。

問題 2 極値

f(x, y) = x3 − 6xy + 3y2 の極値を求めてください。

解答を見る

fx = 3x2 − 6y = 0, fy = −6x + 6y = 0 より y = x, 3x2 − 6x = 0。停留点 (0, 0), (2, 2)。A = 6x, B = −6, C = 6。

(0, 0)：H = −36 < 0 鞍点。(2, 2)：H = 72 − 36 = 36 > 0, A = 12 > 0 → 極小値 f(2, 2) = −4。

問題 3 テイラー展開

f(x, y) = exlog(1 + y) のマクローリン展開を2次の項まで求めてください。

解答を見る

(1 + x + ⋯)(y − y22 + ⋯) の2次まで：y + xy − 12y2。

偏微分係数：f = 0, fx = 0, fy = 1, fxx = 0, fxy = 1, fyy = −1。y + 12(2xy − y2) と一致。

問題 4 連鎖律

z = f(x, y) は C1 級、定数 α に対し x = ucosα − vsinα, y = usinα + vcosα（回転）とします。z2u + z2v = z2x + z2y を示してください。

解答を見る

zu = zxcosα + zysinα, zv = −zxsinα + zycosα。2乗して足すと交差項が打ち消し合い、z2x + z2y。（勾配の長さは座標を回転しても変わらない。）

問題 5 条件付き極値

条件 x2 + y2 = 1 のもとで f = x2 + 2y2 の最大値・最小値を求めてください。

解答を見る

2x = 2λx, 4y = 2λy より x(1 − λ) = 0, y(2 − λ) = 0。

x = 0 なら y =  ± 1、f = 2。x ≠ 0 なら λ = 1、y = 0、x =  ± 1、f = 1。円は有界閉集合なので 最大値 2、最小値 1。

問題 6 勾配

f(x, y) = log(x2 + y2) の点 (1, 2) について、最大の傾きとその向き、および等高線の接線を求めてください。

解答を見る

∇f = 2xx2 + y2, 2yx2 + y2 = 25, 45。最大の傾き |∇f| = 2√5、向き 1√5(1, 2)。

接線：25(x − 1) + 45(y − 2) = 0、すなわち x + 2y = 5。（等高線は原点中心の円なので、接線は半径に垂直。）
