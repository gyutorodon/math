線形写像

「和」と「スカラー倍」を保つ写像を線形写像といいます。平面では、方眼を「平行で等間隔な方眼」に移し、原点を動かさない変換です。

1. 何の話か（直感）

線形空間は「足し算とスカラー倍ができる世界」でした。その構造をこわさずに、ある線形空間から別の線形空間へベクトルを移す写像が線形写像です。

平面 ℝ² から ℝ² への線形写像を図で見ると、次のような特徴があります。

  • 原点は原点に移る
  • 直線は直線に、平行な線は平行な線に、等間隔な目盛りは等間隔な目盛りに移る
  • だから、e1 = (1, 0) と e2 = (0, 1) の行き先さえわかれば、平面全体の行き先が決まる

e1, e2 の行き先を列に並べたものが行列です。下の図で行列の成分を変えて、方眼がどう変形するか見てみましょう。

行列で平面がどう変形するか

スライダーで行列 A の成分を変えると、変形後の方眼が表示されます。青は e1 の行き先 Ae1（A の第1列）、赤は Ae2（第2列）です。「F」の文字で裏返しも確認できます。

2. 定義

定義（線形写像）

V, W を線形空間とします。写像 f : V → W が、すべての u, v ∈ V、c ∈ ℝ について

(L1)f(u + v) = f(u) + f(v)　（和を保つ） (L2)f(cu) = c f(u)　（スカラー倍を保つ）

を満たすとき、f を線形写像といいます。V = W のときは線形変換ともいいます。

定理 1（基本性質）

f が線形写像なら

  • f(0) = 0　（(L2) で c = 0 とする）
  • f(c1v1 + ⋯ + ckvk) = c1f(v1) + ⋯ + ckf(vk)　（1次結合を保つ）
定理 2（ℝⁿ → ℝᵐ の線形写像は行列）

f : ℝⁿ → ℝᵐ が線形写像なら、m × n 行列

A = ( f(e1)　f(e2)　⋯　f(en) )

を使って f(x) = Ax と書けます。逆に、行列 A で定まる写像 x ↦ Ax はいつも線形写像です。

理由：x = x1e1 + ⋯ + xnen に定理1を使うと f(x) = x1f(e1) + ⋯ + xnf(en) = Ax。

3. 具体例

例 1：行列で定まる写像

f(x) = Ax は、行列の分配法則 A(u + v) = Au + Av と A(cu) = c(Au) より線形写像です。たとえば

fxy = x + y2x − y = 112−1xy
例 2：回転

原点のまわりの角 θ の回転は、e1 ↦ (cos θ, sin θ), e2 ↦ (−sin θ, cos θ) なので

Rθ = cos θ−sin θsin θcos θ

で表される線形変換です（上の図の「回転」を押してみてください）。

例 3：微分

D : ℝ[x]3 → ℝ[x]2, D(f) = f ′ は線形写像です。微分の公式 (f + g)′ = f ′ + g′、(cf)′ = cf ′ がちょうど (L1)(L2) です。

例 4：行列の空間の写像

転置 A ↦ tA（M2(ℝ) → M2(ℝ)）や、トレース A ↦ tr A = a11 + a22（M2(ℝ) → ℝ）は線形写像です。積分 f ↦ ∫01 f(x) dx も線形写像です。

例 5：線形写像でないもの（反例）
  • 平行移動 f(x) = x + b（b ≠ 0）：f(0) = b ≠ 0 なので線形ではありません。
  • f(x, y) = (x², y)：f(2 · (1, 0)) = (4, 0) ですが 2f(1, 0) = (2, 0)。(L2) が不成立。
  • f(x, y) = xy：f((1, 0) + (0, 1)) = 1 ですが f(1, 0) + f(0, 1) = 0。(L1) が不成立。
  • 行列式 det : M2(ℝ) → ℝ：det(2A) = 4 det A ≠ 2 det A（det A ≠ 0 のとき）。線形ではありません。

4. よくある間違い

f(x) = 2x + 3 は1次関数なので線形写像である。

高校の「1次関数」と線形写像は別物です。f(0) = 3 ≠ 0 なので線形ではありません。ℝ → ℝ の線形写像は f(x) = ax の形だけです。

f(0) = 0 を確かめたので線形写像である。

f(0) = 0 は必要条件にすぎません。f(x, y) = (x², y) は原点を原点に移しますが線形ではありません。逆に f(0) ≠ 0 なら、それだけで「線形でない」と言えます。

(1, 2) と (3, 4) で (L1) が成り立ったので、線形写像である。

(L1)(L2) は任意の u, v, c で示す必要があります。文字でおいて証明しましょう。線形でないことは反例1つで示せます。

f(e1), f(e2) を行列の行に並べる。

列に並べます。Ae1 は A の第1列なので、A = (f(e1) f(e2)) です。

5. 練習問題

問題 1 教科書 練習問題5 [A] 1 の類題

次の写像は線形写像になるかどうか調べてください。

(1) fx1x2 = x1 − 2x24x2 + 3　　(2) f(x) = 2xx³
(3) fx1x2 = x1 − x22x1x2　　(4) fx1x2x3 = x2x3x1
解答を見る

(1) 線形ではありません。f(0) = (0, 3) ≠ 0。

(2) 線形ではありません。f(2 · 1) = (4, 8) ですが 2f(1) = (4, 2)。(L2) が不成立。

(3) 線形です。f(x) = 1−12001x と行列で書けるからです。

(4) 線形ではありません。f(2 · (0, 1, 1)) = f(0, 2, 2) = (4, 0) ですが 2f(0, 1, 1) = (2, 0)。

見分け方：各成分が xi の「定数倍の和」だけでできていれば線形です。定数項、2乗・3乗、積 xixj があれば線形ではありません（反例を1つ示して確かめます）。

問題 2 教科書 練習問題5 [A] 2 の類題

2次実行列全体 M2 から ℝ への写像 f, g を、A = a11a12a21a22 に対して

f(A) = a11 + 2a22，　g(A) = a11a22

で決めるとき、f と g は線形写像になるか調べてください。

解答を見る

f は線形です。f(A + B) = (a11 + b11) + 2(a22 + b22) = f(A) + f(B)、f(cA) = ca11 + 2ca22 = c f(A)。

g は線形ではありません。単位行列 E について g(2E) = 2 · 2 = 4 ですが 2g(E) = 2。

問題 3 教科書 練習問題5 [A] 7 の類題

ℝ³ のベクトル 110, 011, 111 を、それぞれ ℝ² のベクトル 21, 1−1, 30 にうつす線形写像 f : ℝ³ → ℝ² に対応する行列 A を求めてください。

解答を見る

条件をまとめると AU = Y（U は与えられた ℝ³ のベクトルを列に並べた行列、Y は行き先を列に並べた行列）。よって A = YU−1。

U = 101111011，　U−1 = 01−1−1101−11
A = 2131−1001−1−1101−11 = 20110−1

確認：A(1, 1, 0) = (2, 1)、A(0, 1, 1) = (1, −1)、A(1, 1, 1) = (3, 0)。

別解：e1 = (1, 1, 1) − (0, 1, 1) などと標準基底を与えられたベクトルの1次結合で表し、f(ej) を求めて列に並べても構いません。
