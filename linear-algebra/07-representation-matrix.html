線形代数IIA ・ 第7回

表現行列

線形写像を、基底を決めて「座標の計算」に翻訳したものが表現行列です。作り方の3ステップと、基底を変えたときの公式 A′ = Q⁻¹AP を学びます。

1. 何の話か（直感）2. 定義3. 具体例4. よくある間違い5. 練習問題▶ 動かしてみよう

1. 何の話か（直感）

ℝⁿ → ℝᵐ の線形写像は行列のかけ算で書けました（第5回）。では、微分 D : ℝ[x]2 → ℝ[x]1 のように、ベクトルが数の組でない場合はどうでしょうか。

答えは、基底を決めて座標で考えることです。基底を決めれば、どんな有限次元の線形空間のベクトルも「座標＝数の組」で表せます（第3回）。すると線形写像は「座標を座標に移す写像」になり、それは行列で書けます。この行列が表現行列です。

大事なのは、同じ写像でも基底の選び方で表現行列が変わることです。うまい基底を選ぶと、表現行列が対角行列のような簡単な形になります。これが次の単元「固有値・対角化」につながります。

2. 定義

f : V → W を線形写像、B = (v1, …, vn) を V の基底、C = (w1, …, wm) を W の基底とします。

定義（表現行列）

各 f(vj) を C の1次結合で表します。

f(vj) = a1jw1 + a2jw2 + ⋯ + amjwm　　(j = 1, …, n)

この係数を第 j 列に並べた m × n 行列 A = (aij) を、基底 B, C に関する f の表現行列といいます。まとめて書くと

( f(v1) ⋯ f(vn) ) = ( w1 ⋯ wm ) A
作り方の3ステップ
  1. 定義域の基底の各ベクトル vj の行き先 f(vj) を計算する。
  2. f(vj) を値域の基底 C で表したときの座標を求める。
  3. その座標を第 j 列に並べる。
定理 1（座標で見た f）

v の B 座標を x とすると、f(v) の C 座標は Ax です。

ℝⁿ → ℝᵐ で f(x) = Mx（M は標準基底での行列）、基底のベクトルを列に並べた行列を B, C とすると A = C−1MB。

定理 2（基底を変えたときの表現行列）

V の基底を B → B′（変換行列 P）、W の基底を C → C′（変換行列 Q）に取りかえると、新しい表現行列は

A′ = Q−1AP

特に V = W で、両側で同じ基底を使う（B = C, B′ = C′）なら A′ = P−1AP。

理由：B′ 座標 x′ → B 座標 Px′ → f で C 座標 APx′ → C′ 座標 Q−1APx′（第4回の座標変換の公式）。

3. 具体例

例 1：微分の表現行列

D : ℝ[x]2 → ℝ[x]1, D(f) = f ′、基底 B = (1, x, x²), C = (1, x)。

D(1) = 0= 0 · 1 + 0 · xD(x) = 1= 1 · 1 + 0 · xD(x²) = 2x= 0 · 1 + 2 · x

係数を列に並べて A = 010002（2 × 3 行列）。

確認：f = 3 + 5x + 4x² の座標 (3, 5, 4) に A をかけると (5, 8)。実際 f ′ = 5 + 8x。

例 2：うまい基底で対角行列に

f(x) = Mx, M = 2112 を、基底 B = C = ((1, 1), (1, −1)) で表します。

f(1, 1) = (3, 3) = 3 · (1, 1) + 0 · (1, −1)，　f(1, −1) = (1, −1) = 0 · (1, 1) + 1 · (1, −1)

よって表現行列は A = 3001（対角行列）。この基底の方向には「3倍」「1倍」に伸びるだけ、という f の正体が見えます。

例 3：定義域と値域で基底が違う場合

f : ℝ³ → ℝ², f(x, y, z) = (x + y, y + z)、B = ((1, 0, 0), (1, 1, 0), (1, 1, 1)), C = ((1, 0), (1, 1))。C での座標は「(p, q) = (p − q) · (1, 0) + q · (1, 1)」で求められます。

よって A = 110012。

4. よくある間違い

f(vj) の座標を表現行列の第 j 行に並べる。

列に並べます。行に並べると転置行列になってしまいます。「A の第 j 列 = Aej = vj の行き先」と覚えましょう。

f(vj) の成分（標準座標）をそのまま並べる。

値域の基底 C が標準基底でないときは、f(vj) をC で表し直した座標を並べます（ステップ2）。例3で f(1, 1, 0) = (2, 1) の列が (1, 1) になっているのはこのためです。

基底を変えたときの表現行列を PAP−1 と計算する。

正しくは P−1AP です。「右の P で新しい座標を古い座標に直し、A で写し、左の P−1 で新しい座標に戻す」という順番で考えると間違えません。

基底の順番は気にしなくてよい。

基底の順番を入れ替えると、表現行列の列（や行）も入れ替わります。基底は順番つきで扱います。

5. 練習問題

問題 1 教科書 練習問題5 [A] 13 の類題

2次以下の多項式全体からなる線形空間の線形変換 T を

T(f(x)) = 2f(x) + f(1)x

で決めるとき、T の基底 {1, x, x²} に関する表現行列を求めてください。

解答を見る
T(1) = 2 + x= 2 · 1 + 1 · x + 0 · x²T(x) = 2x + 1 · x = 3x= 0 · 1 + 3 · x + 0 · x²T(x²) = 2x² + 1 · x= 0 · 1 + 1 · x + 2 · x²

係数を列に並べて

A = 200131002

f(1) は「f に 1 を代入した数」です。f = x² なら f(1) = 1 です。

問題 2 教科書 練習問題5 [A] 9 の類題

次の ℝ³ の線形変換に対応する行列、および基底 { 100, 110, 111 } に関する表現行列を求めてください。

x1x2x3 ↦ x1 + x2x2 − x32x1 + x3
解答を見る

対応する行列（標準基底での表現行列）は

M = 11001−1201

基底を列に並べた行列を B = 111011001 とすると、表現行列は B−1MB。

MB = 122010223，　B−1 = 1−1001−1001，　B−1MB = 112−2−1−3223

「動かしてみよう」の ℝ³ → ℝ³ の例「問題2」でも確認できます。第1列の確認：f(1, 0, 0) = (1, 0, 2)。1 · (1, 0, 0) − 2 · (1, 1, 0) + 2 · (1, 1, 1) = (1, 0, 2) ✓

問題 3 教科書 練習問題5 [A] 12 の類題

dim V = 3 として、V の線形変換 f の基底 { a1, a2, a3} に関する表現行列を A = 12001−1102 とします。このとき、f の基底 { a1, a1 + a2, a1 + a2 + a3 } に関する表現行列を求めてください。

解答を見る

基底変換の行列は（新しい基底の係数を列に並べて）P = 111011001。定理2より A′ = P−1AP。

AP = 133010113，　P−1 = 1−1001−1001
A′ = P−1AP = 123−10−3113

確認：上の「動かしてみよう」で ℝ³ → ℝ³ の例「問題3」を選ぶと、同じ結果になります。
